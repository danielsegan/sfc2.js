# Tactical HUD Interaction Audit (SFC2 CE 2.670 vs `main`)

Status: draft v0.4 (2026-11-25, updated alongside PR 4b after Wintermute's live CE 2.670 interactive pass). Owner: UI & Art Director.
Baseline branch: `main` (`e224292`, with PRs 1–4 landed). Reference baseline: *Starfleet Command II: Empires at War — Community Edition* (CE) 2.670.

Purpose: Daniel's direction (2026-11-25) keeps our modern visual style (`docs/ui/style-guide.md`, `docs/ui/hud-layout.md`) while bringing controls, feedback, and HUD behaviour closely in line with the original SFC2. This audit compares each interaction area against the repo, cites exact files and functions, rates every gap (`High` / `Med` / `Low`), records intentional deviations from CE, and ends with a ranked PR plan ordered **smallest first** within priority.

**Sources & verification marks:**

- **CE reference notes (Wintermute, 2026-11-25)**: Clean-room behaviour notes in `/workspace/sfc2-screens/ce-ref/ce-ui-notes.md`, cited below as `CE reference notes (Wintermute, 2026-11-25), observed` when directly observed in CE 2.670 captures or live `xdotool` probes, or noted as a `[gap]` / **TO VERIFY** when not triggered in the live pass.
- **M2**: *Starfleet Command II* Gameplay Manual & Reference Guide (TrekCore mirror, `sfc2.pdf`).
- **G1 / G2 / XP**: Public community guides (GameFAQs `faqs/10875`, `faqs/17237`, TrekCore `faq.html` / `walkthrough.txt`, XenoCorp `power_management.htm`).
- **Docs**: `docs/ui/hud-layout.md`, `docs/ui/hud-spec.md`, `docs/ui/keymap.md`, `docs/ui/modern-ux.md`, `docs/rules/`.
- **Intentional deviations (Daniel's decisions, 2026-11-24 / 2026-11-25)**:
  - **Space mouse model**: In CE 2.670, left-clicking open space steers and right-clicking open space does nothing (`CE reference notes (Wintermute, 2026-11-25), observed`). By Daniel's 2026-11-24 decision (`docs/ui/hud-layout.md`), `sfc2.js` keeps **left-click to steer** and uses **right-click to target** in space (plus `Alt+left` / middle-drag to orbit), rather than leaving right-click unbound.
  - **Default keymap**: CE 2.670 uses legacy multi-tab defaults (`A`/`S`, `Z`/`Shift+Z`, `Y/T/U/\`/Space`, `1–4`, `F1–F12`, etc.), whereas `sfc2.js` keeps the **Modern** keymap (`docs/ui/keymap.md`) as the default by Daniel's decision (`hud-layout.md` §8 Q11) and will add `"SFC2 Classic"` as an opt-in preset.
- **TO VERIFY**: Remaining live-pass gaps flagged in Wintermute's notes — **audio cues** (unobservable under headless `[Sound] disable=1`), **initial 3D click lock on an untargeted ship**, **target subsystem box clicking** (whether close scan/key enables selection), **Damage Control clicks while a slot is actually damaged**, **right-click on shield wedges**, and **weapon group ovals after assigning custom `Ctrl+1..4` groups**.
- **Boundary rule**: The HUD reads `ViewModel` (`engine/view/view-model.ts`) and dispatches `Command` / `DuelMatch` calls (`engine/duel/match.ts`) only. Where closing a gap needs a new sim verb or `ViewModel` field, that dependency is flagged so Engine / Combat can wire it cleanly without HUD-side sim writes.
