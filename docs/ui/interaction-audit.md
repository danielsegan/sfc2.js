# Tactical HUD Interaction Audit (SFC2 CE 2.670 vs `main`)

Status: draft v0.2 (2026-11-25, updated alongside PR 4 after CE 2.670 reference pass). Owner: UI & Art Director.
Baseline branch: `main` (`1fc9216`, with PRs 1–3 landed). Reference baseline: *Starfleet Command II: Empires at War — Community Edition* (CE) 2.670.

Purpose: Daniel's direction (2026-11-25) keeps our modern visual style (`docs/ui/style-guide.md`, `docs/ui/hud-layout.md`) while bringing controls, feedback, and HUD behaviour closely in line with the original SFC2. This audit compares each interaction area against the repo, cites exact files and functions, rates every gap (`High` / `Med` / `Low`), and ends with a ranked PR plan ordered **smallest first** within priority.

**Sources & verification marks:**

- **CE reference notes (Wintermute, 2026-11-25)**: Clean-room behaviour notes in `/workspace/sfc2-screens/ce-ref/ce-ui-notes.md`, cited below as `CE reference notes (Wintermute, 2026-11-25), observed` when seen directly in CE 2.670 screenshots or verified harness runs, or `CE reference notes (Wintermute, 2026-11-25), inferred` when deduced from layout/controls and still needing live click/drag confirmation.
- **M2**: *Starfleet Command II* Gameplay Manual & Reference Guide (TrekCore mirror, `sfc2.pdf`).
- **G1 / G2 / XP**: Public community guides (GameFAQs `faqs/10875`, `faqs/17237`, TrekCore `faq.html` / `walkthrough.txt`, XenoCorp `power_management.htm`).
- **Docs**: `docs/ui/hud-layout.md`, `docs/ui/hud-spec.md`, `docs/ui/keymap.md`, `docs/ui/modern-ux.md`, `docs/rules/`.
- **TO VERIFY**: Any detail not yet observed directly in CE 2.670 (either inferred in Wintermute's notes or left for a free live copy).
- **Boundary rule**: The HUD reads `ViewModel` (`engine/view/view-model.ts`) and dispatches `Command` / `DuelMatch` calls (`engine/duel/match.ts`) only. Where closing a gap needs a new sim verb or `ViewModel` field, that dependency is flagged so Engine / Combat can wire it cleanly without HUD-side sim writes.
