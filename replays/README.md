# Synthetic replay corpus

These `.s2replay` files are generated by `pnpm replay:record` from the scripts in `engine/replay/scenarios/`. They are made-up seeds, commands, and hash timelines. They are not recordings from a Starfleet Command 2 install and they contain no game assets.

`pnpm replay:check` replays them and fails if a hash diverges. See `docs/engine/replay.md`.
